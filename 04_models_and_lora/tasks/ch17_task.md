# 实操 17：认识你的模型与许可

> 对应章节：[第 17 章 模型家族](../docs/ch17_model_families.md) ｜ 预计耗时：20 分钟
> 状态：`[已完成]`

## 目标

搞清楚自己手上模型属于哪个家族、最佳分辨率、许可条款，建立「模型决定玩法」的认知；不下载新东西。

## 前提

- [ ] ComfyUI 已装好，手里至少有 1 个模型文件

## 步骤

1. **识别家族**：打开你 `models/checkpoints/`（或 `diffusion_models/`）里的模型文件名，
   结合你下载来源的页面，判断它属于 SD1.5 / SDXL / FLUX 哪个家族，填进记录表。

2. **核对最佳分辨率**：按家族查最佳分辨率（SD1.5=512、SDXL=1024、FLUX≈1024，见 [ch17 17.1](../docs/ch17_model_families.md#c17-01)），
   确认你之前出图用的尺寸是否匹配。

3. **查许可**：回到你下载模型的页面（Hugging Face / Civitai），找到 License 字段，记录是否允许商用。
   （来源站见 [附录 D](../../90_appendix/docs/appD_resources.md)）

4. **对照家族差异**：如果你只用过 SD1.5，读一遍 [ch20](ch20_workflow_variants.md) 里 SDXL/FLUX 的节点差异预告，
   建立「换家族＝换工作流」的预期。

## 验收标准

- [ ] 记录表里填出模型的家族、分辨率、许可
- [ ] 能说出自己用的尺寸是否匹配模型

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| SD1.5 模型用 1024 出图 | 易出重复头/畸形 | 超出训练分辨率，见 ch17 17.1 |
| 把 SD1.5 的 LoRA 装给 SDXL 用 | 加载失败或无效 | LoRA 与家族绑定，见 ch17 17.1 |

## 常见问题

- 看不出家族 → 看下载页标题/说明，通常写明 SD1.5/SDXL/FLUX
- 许可条款看不懂 → 用翻译工具读关键词（commercial use / license）；有疑问按不允许商用处理
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
