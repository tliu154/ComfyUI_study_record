### 10.1 局部重绘解决什么问题

**概念定义**：图生图（[ch09](ch09_img2img.md)）改的是**整张图**——即使 denoise 低，多少也会影响全局。
但很多时候你只想改**一个局部**：去掉路人、换个衣服颜色、把破损的地方补上、给空地加个物体。
局部重绘就是「只重画蒙版圈定的区域，区域外保持原图像素不变」。

**直觉类比**：像**用修正液改作业**——
图生图是把整页重写一遍（可能笔迹全变），局部重绘是只在你涂了修正液的那一小块重新写，
其余字迹原封不动。蒙版就是你涂修正液的范围。

**界面 / 参数**：典型用途——
- **去除**：路人、水印、多余物体（蒙版圈住它，提示词写背景应该长什么样）
- **添加**：空地上加个物体（蒙版圈空地，提示词写要加什么）
- **替换**：换衣服/换表情/换背景物件
- **修补**：老照片破损、画面瑕疵

**常见误区**：
- ❌「局部重绘和图生图一样」—— 不一样。图生图全局受影响；局部重绘区域外像素级保留。
- ❌「局部重绘能改蒙版外的东西」—— 不能，蒙版外原样保留（除非掩码边缘太软导致轻微渗透，见 10.4）。

> **够用边界**：知道「局部重绘 = 蒙版圈哪改哪、圈外不动」就够了。
> **和已有认知的差异**：普通图像编辑里你要做「选区 → 内容识别填充」，这里是「蒙版 → diffusion 重新生成选区内容」——
> 结果更智能（能凭提示词「生成」出合理内容），但也需要调提示词和参数，不是一键填充。

### 10.2 制作蒙版（Mask）

**概念定义**：蒙版（Mask）是一张**黑白图**：白色 = 要重画的区域，黑色 = 保留不动的区域（灰 = 部分影响）。
ComfyUI 里最常见的做法是用 `Paint Mask` 功能在图上直接涂。

**直觉类比**：像**给照片贴遮蔽胶带**——你要喷漆的地方用胶带之外的部分遮住。
白色的地方「揭开了胶带」会被重画，黑色的地方「贴着胶带」被保护。

**界面 / 参数**：制作蒙版的常用方式——
1. **Load Image 上传后点「Open in Mask Editor」**（或图片节点的绘画按钮）：
   在弹出界面里用画笔涂白要改的区域，涂完保存，节点会同时输出 IMAGE 和 MASK
2. **外部做好蒙版图**：用 PS/画图和原图同尺寸的黑底白涂图片，用 `Load Image` + 提取 alpha/灰度转 MASK
3. 一些自定义节点包提供更方便的蒙版绘制工具

关键：**蒙版尺寸必须和原图一致**（宽高相同），否则对不上。

**常见误区**：
- ❌「蒙版白色=保留、黑色=重画」—— 反了！**白色=重画，黑色=保留**。这是最高频的搞反点。
- ❌「随便涂一下边缘就行」—— 涂得太粗糙会重画过多或过少；边缘软硬影响融合（见 10.4）。
- ❌「蒙版图尺寸可以和原图不同」—— 不行，必须一致。

> **够用边界**：记住「**白改黑留、蒙版和原图同尺寸**」，会用 Mask Editor 涂一块就够了。
> 各种高级蒙版生成（自动抠图 segment anything）按需再学。
> **和已有认知的差异**：和 PS 蒙版「白色显示、黑色隐藏」的约定**方向一致**（白=生效），
> 只是这里「生效」指的是「被重画」而非「被显示」。

### 10.3 两条路线：SetLatentNoiseMask vs Inpaint 模型

**概念定义**：把蒙版接入工作流有两条主流路线：

**路线 A：`SetLatentNoiseMask`（通用模型也能局部重绘）**
- 用 [ch09](ch09_img2img.md) 的图生图流程（原图 VAE Encode 成 latent）
- 加 `SetLatentNoiseMask`，输入 latent + mask，输出带蒙版的 latent 给 KSampler
- 配普通 checkpoint 即可；靠蒙版限制去噪区域

**路线 B：Inpaint 专用模型 + `InpaintModelConditioning`**
- 用专门的 inpaint checkpoint（如 SD1.5 inpaint 模型）
- 用 `InpaintModelConditioning` 节点，吃 image + mask + positive/negative，吐出 conditioning 和 latent
- 专为局部重绘训练，边缘融合通常更自然

**直觉类比**：
- 路线 A = 用普通油漆工（通用模型）+ 胶带（蒙版）限定范围，够用
- 路线 B = 请专门的修补师傅（inpaint 模型），带着专业工具和训练，补得更自然

**界面 / 参数**：两条路线的接线骨架——
```
【路线 A：SetLatentNoiseMask】
Load Image(IMAGE) → VAE Encode → SetLatentNoiseMask(latent)
Load Image(MASK) ─────────────→ SetLatentNoiseMask(mask)
SetLatentNoiseMask → KSampler(latent_image)
（Checkpoint 用普通模型，denoise 常设较高如 0.9~1）

【路线 B：InpaintModelConditioning】
Load Image(IMAGE + MASK) → InpaintModelConditioning(image, mask)
CLIP Text Encode 正/负 ──→ InpaintModelConditioning(positive, negative)
InpaintModelConditioning → KSampler 的 positive/negative/latent_image
（Checkpoint 用 inpaint 专用模型）
```

**常见误区**：
- ❌「两条路线混着接」—— 选一条走。普通模型走 A，有 inpaint 模型走 B。
- ❌「路线 A 也要下 inpaint 模型」—— 不用，这正是 A 的好处：普通模型就能局部重绘。
- ❌「denoise 随便设」—— 局部重绘常把 denoise 设高（0.9~1），因为要在蒙版区充分重画，靠蒙版而非 denoise 控制范围。

> **够用边界**：新手先用**路线 A**（不用额外下模型），能局部改图即可。路线 B 等追求边缘质量再上。
> 两条路线内部的 conditioning 机制差异跳过。
> **和已有认知的差异**：「同一件事有两条技术路线」在 ComfyUI 很常见——
> 一条省资源通用（A），一条专用效果好（B）。选型思路和工程里「通用方案 vs 专用方案」一致。

### 10.4 边缘融合与参数

**概念定义**：局部重绘的质量关键在**蒙版边缘的融合**——重画区和保留区交界处要自然过渡，不能有明显接缝。
影响因素：蒙版边缘软硬、denoise、以及（路线 B 的）inpaint 模型的补边能力。

**直觉类比**：像**补墙**——你补的那块和旧墙之间要打磨过渡，
否则补痕一眼看出来。蒙版边缘就是「打磨范围」：太硬有接缝，太软会溢出到保留区。

**界面 / 参数**：改善融合的办法——
- **蒙版画笔用软边/羽化**：边缘有一点灰（半透明）过渡，比纯黑白硬边更自然
- **蒙版稍微涂大一点**：让重画区略微覆盖问题区域外围，避免边缘残留
- **denoise 设高**（0.9~1）：让蒙版区充分重画，和周围更协调
- **提示词描述周围环境**：告诉模型边缘外是什么，帮助衔接（如改物体时写清背景）
- 有专门的边缘处理节点/自定义节点可进一步改善（按需）

**常见误区**：
- ❌「边缘越硬越好」—— 太硬容易有接缝；适度软边更自然。
- ❌「重绘出来和周围格格不入就无解」—— 调软边、调大蒙版、改提示词描述环境，通常能改善。
- ❌「denoise 低一点更保真」—— 局部重绘里 denoise 太低会导致蒙版区重画不充分，反而拼接感强。

> **够用边界**：记住「软边 + 蒙版略大 + denoise 高 + 提示词描述环境」这套改善组合就够了。
> 边缘融合的高级算法跳过。
> **和已有认知的差异**：PS 的瑕疵修复是局部像素算法，不影响语义；diffusion 局部重绘会「理解」这块该画什么，
> 但正因为是生成的，边缘是否和谐需要你调参引导——多了一个「导演」的职责。

---

## 小结

- 局部重绘 = 蒙版圈哪改哪、圈外像素级保留；用来去除/添加/替换/修补局部。
- 蒙版**白=重画、黑=保留**，尺寸和原图一致；用 Mask Editor 涂。
- 两条路线：`SetLatentNoiseMask`（普通模型，新手首选）vs `InpaintModelConditioning`（专用模型，边缘更好）。
- 融合靠软边 + 蒙版略大 + denoise 高 + 提示词描述环境。
