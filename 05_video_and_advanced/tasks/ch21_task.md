# 实操 21：跑一段最小视频（或看懂结构）

> 对应章节：[第 21 章 视频生成入门](../docs/ch21_video_basics.md) ｜ 预计耗时：40 分钟
> 状态：`[已完成]`
> 说明：视频很吃显存。本任务分两档——**A 档真跑**（显存够），**B 档看懂**（跑不动就研究结构，也算完成）。

## 目标

A 档：用 AnimateDiff 跑出一段 2~3 秒短视频，记录帧数/尺寸/显存。
B 档：导入一条视频模板，逐节点标出「图像链 / 运动模块 / 多帧 latent / 合成视频」四部分。

## 前提

- [ ] 熟悉文生图工作流（ch03~ch08）
- [ ] A 档：已装视频节点包（如 AnimateDiff-Evolved）+ 下载 motion module 和视频模型（见 [ch24](../../06_ecosystem/docs/ch24_manager.md)、[附录 D](../../90_appendix/docs/appD_resources.md)）

## 步骤（A 档：真跑）

1. **从模板起步**：导入一条 AnimateDiff 文生视频模板（模板入口见 [ch20 20.4](../../04_models_and_lora/docs/ch20_workflow_variants.md#c20-04)），放好模型文件，按 `R` 刷新。

2. **设最小参数**：帧数 8~16，尺寸 512 附近，steps 20，先用默认提示词。

3. **执行**：Queue Prompt，观察显存占用与耗时。跑完得到一串帧，合成短视频。

4. **记录**：填下方表格。

### 步骤（B 档：看懂结构，跑不动时）

1. 导入视频模板，不要求跑通。
2. 在图上标出四部分：模型/提示词（图像链）、运动模块（AnimateDiff）、多帧 latent、图像序列合成视频。对照 [ch21 21.3](../docs/ch21_video_basics.md#c21-03)。
3. 记录你卡在哪一步（缺模型 / 显存不足 / 节点缺失），填表。

## 验收标准

- A 档：出一段短视频，记录帧数/尺寸/显存
- B 档：能指出视频工作流四个组成部分，说清它和文生图的差别
- 两档都算完成，不因显存不足而卡住学习

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 帧数翻倍 | 显存/耗时大增，甚至 OOM | 显存≈图像×帧数，见 ch21 21.4 |
| 去掉运动模块 | 变成一堆独立的图，没有连贯运动 | 运动模块负责帧间关联，见 ch21 21.3 |
| 分辨率拉到 1024 | 更容易 OOM | 尺寸×帧数双重放大，见 ch21 21.4 |
