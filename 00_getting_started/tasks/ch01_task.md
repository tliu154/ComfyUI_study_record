# 实操 01：摸清你的运行环境

> 对应章节：[第 1 章 ComfyUI 是什么](../docs/ch01_what_is_comfyui.md) ｜ 预计耗时：10 分钟
> 状态：`[已完成]`

## 目标

搞清楚自己的显卡型号、显存大小、系统版本，据此**选定后面用哪种安装方式**。
不装任何东西，纯摸底。

## 前提

无。一台能上网查资料的电脑即可。

## 步骤

1. **查显卡型号和显存**（Windows）：
   - 按 `Ctrl + Shift + Esc` 打开任务管理器 → 「性能」标签 → 点「GPU 0」
   - 右上角能看到显卡型号（如 `NVIDIA GeForce RTX 3060`），下方「专用 GPU 内存」就是显存
   - 记下这两个值

2. **确认系统版本**：
   - `Win + R` 输入 `winver` 回车，记下 Windows 版本（如 Windows 11 23H2）

3. **对照决策表选安装路线**（来自 [ch01 1.4 节](../docs/ch01_what_is_comfyui.md#c01-04)）：

   | 你的情况 | 后面选 |
   |---|---|
   | N 卡，显存 ≥ 8G | 本地：Windows 便携包（[ch02 2.2](../docs/ch02_installation.md#c02-02)）|
   | N 卡，显存 4~6G | 本地便携包 + 低显存模式（[ch26](../../06_ecosystem/docs/ch26_performance.md)）|
   | 无独显 / 显存 ≤ 4G / Mac | 云端 Comfy Cloud（[ch02 2.4](../docs/ch02_installation.md#c02-04)）|

## 验收标准

- [ ] 能说出自己的显卡型号 + 显存大小
- [ ] 在下面记录表里填好，并圈定了一条安装路线

## 改一改会怎样（小实验）

| 改动 | 预期现象 | 为什么 |
|---|---|---|
| 假设显存减半（如 8G→4G）| 能用但只能出小图 / 要降精度 | 显存决定一次能装下多大的模型和数据 |

## 常见问题

- 任务管理器里 GPU 看不到型号 → 可能是集成显卡，按「无独显」路线走云端即可
- 显存数值和商家宣传不符 → 看「专用 GPU 内存」，共享内存不算数
- 其它 → [附录 C 故障排查](../../90_appendix/docs/appC_troubleshooting.md)
