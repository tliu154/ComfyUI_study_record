### 2.1 四种安装方式对比

**概念定义**：ComfyUI 官方提供多种安装形态，本质是「别人帮你封装了多少」的区别。
封装越多越省事，但越不灵活。

**直觉类比**：像买电脑——
- **桌面版** = 品牌整机：插电就能用
- **便携包** = 准系统：装好了系统，开机稍作设置就能用，最主流
- **源码安装** = 自己攒机：最灵活，但要自己装驱动、配环境
- **云端** = 网吧电脑：不用买，按时间租，网好就能用

**界面 / 参数**：四种方式一览——

| 方式 | 适合谁 | 难度 | 要 Python 吗 | 显存要求 |
|---|---|---|---|---|
| **Comfy Desktop** | 完全新手、想插电就用 | ★ | 否 | 取决本地显卡 |
| **Windows 便携包 Portable** | 主流本地用户（推荐）| ★★ | 否（自带）| 取决本地显卡 |
| **源码安装 Manual / git** | 要改代码、装 Linux、深度定制 | ★★★ | 是 | 取决本地显卡 |
| **Comfy Cloud** | 无独显 / Mac / 想零安装 | ★ | 否 | 云端显卡，按套餐 |

**常见误区**：
- ❌「必须会 Python 才能装」—— 桌面版和便携包**自带运行环境**，完全不用管 Python。
  只有源码安装才需要。
- ❌「便携包是临时方案，不专业」—— 恰恰相反，便携包是官方主推的 Windows 方案，绝大多数教程默认你用它。

> **够用边界**：这一节只要能对号入座选出一条路。选错了没关系，重装就是。
> 源码安装的 Linux / 多显卡细节本篇不展开，需要时看官方仓库 README。
> **和已有认知的差异**：如果你用 Python 习惯了 `pip install` + venv，源码安装那套你会很熟；
> 但新手请**直接跳过源码安装**——ComfyUI 的依赖（CUDA 版 torch）用 pip 装很容易踩坑，没必要第一天就挑战。

### 2.2 Windows 便携包实战（Portable）

**概念定义**：便携包是官方打包好的一个压缩包，里面**Python、依赖、ComfyUI 全都有**，
解压即用。这是 Windows 上最主流的方式。

**直觉类比**：像一个**装满工具的移动工具箱**，拉到哪个文件夹都能开工，不用先装工具。

**界面 / 参数**：步骤（照做即可）——

1. **下载**：到官方 GitHub 仓库 `Comfy-Org/ComfyUI` 的 Releases 页，
   或 comfyanonymous/ComfyUI 的 README 里找 Windows Portable 下载链接
   （官方入口汇总见 [附录 D](../../90_appendix/docs/appD_resources.md)）。
2. **解压**：随便解压到一个**路径不含中文和空格**的目录，例如 `D:\ComfyUI\`。
   > 路径有中文/空格是新手最常见的启动失败原因之一，务必避开。
3. **启动**：双击解压目录里的 `run_nvidia_gpu.bat`（N 卡）。
   会先弹出一个黑色命令行窗口（在装依赖/启动服务），耐心等。
4. **打开界面**：看到命令行里出现类似 `To see the GUI go to: http://127.0.0.1:8188`，
   在浏览器打开 `http://localhost:8188`。看到画布就成功了。

得到的关键目录（`ComfyUI_windows_portable\ComfyUI\` 下）：
- `models\checkpoints\` —— 放大模型的地方（[ch05](../../01_core_nodes/docs/ch05_loaders.md) 会讲）
- `output\` —— 出图保存的位置
- `main.py` —— 源码安装的启动入口（便携包不用管）

**常见误区**：
- ❌「双击后黑窗口一闪而过就没了」—— 多半是路径含中文/空格，或依赖没装完。先看解压路径。
- ❌「浏览器打不开 8188」—— 服务还没起来，等命令行出现上面的提示再开；或端口被占用。见 [附录 C](../../90_appendix/docs/appC_troubleshooting.md)。
- ❌「下载的模型放桌面就行」—— 不行，必须放进 `models\checkpoints\`，否则列表里看不到，见 [ch18](../../04_models_and_lora/docs/ch18_model_files.md)。

> **够用边界**：会「解压 → 双击 bat → 浏览器打开」就够开始学习了。
> 更新、高级启动参数在 [2.5](#c02-05)，现在可以先跳过。
> **和已有认知的差异**：便携包把 Python 环境**塞进压缩包里**，和你想的「装到系统里」完全不同——
> 它是自包含的，删掉文件夹就等于卸载干净，不会污染系统。

### 2.3 comfy-cli 捷径

**概念定义**：`comfy-cli` 是官方出的命令行工具，用几条命令就能**安装、启动、更新、装插件**，
是介于便携包和源码之间的「自动化」方案。

**直觉类比**：便携包是手动挡，comfy-cli 是自动挡——你想做的事（装、启动、更新）一句话搞定。

**界面 / 参数**：最常用的几条命令——

```bash
pip install comfy-cli          # 先装这个工具（需要 Python 环境）
comfy install                  # 一条命令装好 ComfyUI（会问几个选项）
comfy launch                   # 启动
comfy update                   # 更新
comfy nodes install <包名>      # 装自定义节点（第 7 篇 ch24 会用）
```

**常见误区**：
- ❌「comfy-cli 和便携包必须二选一、装了两个会冲突」—— 它们是不同的安装路线，选一条即可，别混着装。
- ❌「它要 pip，所以不是新手友好的」—— 对纯新手确实多一步（要 Python），
  所以本笔记推荐新手走 [2.2 便携包](#c02-02)；comfy-cli 更适合已经熟悉命令行的人。

> **够用边界**：新手可以**整节跳过**，用便携包完全够。等你嫌手动更新麻烦时再回来。
> **和已有认知的差异**：如果你懂 Python 包管理，这条路径最合你胃口；把它当成一个「ComfyUI 专属的包管理器 + 启动器」。

### 2.4 云端零安装（Comfy Cloud）

**概念定义**：Comfy Cloud 是官方托管的云端 ComfyUI，浏览器打开就能用，显卡在云端，按套餐计费。
适合没独显、Mac、或不想折腾本地环境的人。

**直觉类比**：像**云游戏**——不用买显卡，网速够就能玩，但按时长/套餐花钱。

**界面 / 参数**：
- 打开 `cloud.comfy.org`，登录，选一个模板工作流（如 Z-Image-Turbo 文生图）
- 直接在浏览器里改提示词、点运行，出图在云端
- 优缺点对照：

| 优点 | 缺点 |
|---|---|
| 零安装、不吃本地显卡 | 按套餐付费 |
| 随时随地、多设备 | 依赖网络 |
| 官方模板开箱即用 | 自定义程度受平台限制，模型未必齐全 |

**常见误区**：
- ❌「云端 = 数据不安全」—— 敏感内容还是本地更稳妥；普通练习用云端没问题。
- ❌「云端学到的和本地不一样」—— 界面和操作逻辑一致，技能是通用的，换到本地无缝衔接。

> **够用边界**：会用浏览器打开模板、改提示词、点运行即可。
> 云端的 MCP / 高级 API 是 [ch23](../../05_video_and_advanced/docs/ch23_multimodal.md)、[ch25](../../06_ecosystem/docs/ch25_api_automation.md) 的事，现在不用管。
> **和已有认知的差异**：本地是「一次投入、长期免费（电费除外）」，云端是「按需付费、零维护」——
> 和「买服务器 vs 用云主机」是同一个取舍。

### 2.5 启动、更新与目录结构

**概念定义**：装好之后的日常三件事：**启动**（用）、**更新**（跟版本）、**认目录**（放模型/找出图）。

**直觉类比**：像开店——每天开门（启动）、定期装修升级（更新）、知道仓库和货架在哪（目录）。

**界面 / 参数**：
- **启动**：双击 `run_nvidia_gpu.bat`；浏览器开 `http://localhost:8188`
- **更新**：便携包目录里有 `update.bat`（或 `update_comfyui_and_python_dependencies.bat`），双击运行；
  comfy-cli 用户用 `comfy update`
- **刷新模型列表**：往模型目录放了新文件后，在界面里按 `R` 键（或重启）让它重新扫描
- **关键目录**（`ComfyUI\` 下）：

| 目录 | 放什么 |
|---|---|
| `models\checkpoints\` | 大模型 checkpoint（[ch05](../../01_core_nodes/docs/ch05_loaders.md)）|
| `models\loras\` | LoRA（[ch19](../../04_models_and_lora/docs/ch19_lora.md)）|
| `models\controlnet\` | ControlNet 模型（[ch13](../../03_control_and_refine/docs/ch13_controlnet.md)）|
| `input\` | 你上传给「Load Image」的图 |
| `output\` | 生成的图默认存这里 |
| `workflows\` | 保存的工作流 JSON（新版本）|

**常见误区**：
- ❌「放了模型但列表里没有」—— 没刷新。按 `R` 或重启；还不行检查是否放错目录、文件名是否带奇怪后缀。
- ❌「更新会把我的模型和工作流删掉」—— 正常更新只动程序文件，不动 `models/`、`output/`、`workflows/`。
  但**更新前备份工作流 JSON** 是好习惯。
- ❌「8188 端口能改吗」—— 能，启动参数加 `--port 别的数字`，一般不用改。

> **够用边界**：记住「双击启动、浏览器 8188、按 R 刷新模型、模型放 models 对应子目录、出图在 output」这一串就够日常用了。
> 启动参数、多 GPU 配置等进阶内容见 [ch26](../../06_ecosystem/docs/ch26_performance.md)。
> **和已有认知的差异**：ComfyUI 是**本地网页服务**——程序跑在你机器上，浏览器只是界面。
> 所以关掉浏览器服务还在跑，关掉命令行窗口服务才停。这和纯网页应用不一样。

## 小结

- 四条安装路：桌面版 / 便携包（Windows 新手首选）/ 源码 / 云端；选一条走到底。
- 便携包：解压到无中文路径 → 双击 bat → 浏览器开 `localhost:8188`。
- 日常：双击启动、浏览器 8188、`R` 刷新模型、模型放 `models\` 子目录、出图在 `output\`。
